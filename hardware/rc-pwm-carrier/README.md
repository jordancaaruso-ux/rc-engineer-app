# RC PWM Logger — Carrier Board (rev A)

Small carrier PCB for the **ESP32-S3-DevKitC-1** dev board. The devkit plugs into two
socket rows; the carrier provides receiver-rail power, PWM voltage dividers, and
servo-lead connectors. Replaces the loose-wire prototype in
`../rc-pwm-logger/PROTOTYPE_BUILD_PACKET.md` with a track-worthy, JLCPCB-assembled board.

**This is NOT the full custom board** — that project (`../rc-pwm-logger/V1.*`) is parked.
The carrier exists to prove the passive-tap concept and the data's value cheaply.

## Locked decisions (founder, 2026-07-18)

| Decision | Choice |
|---|---|
| Compute | ESP32-S3-DevKitC-1 (USB-C, WROOM-1 N8) — plugs in, never soldered |
| Power | From the receiver/BEC rail (5.5–8.4 V) via on-board buck to 5 V |
| Channels | 2 — steering + throttle/brake, standard 3-pin servo headers |
| Assembly | JLCPCB assembles everything incl. through-hole (founder does zero soldering) |
| Sessions | ~10 min target (dev-board internal flash is enough; no SD, no NOR) |

## Safety rule (inherited, non-negotiable)

**Listener only.** The carrier taps receiver PWM through series dividers; it is never in
the receiver→servo/ESC path. The car must drive identically with the logger present,
absent, unpowered, or rebooting. Servo Y-leads at the receiver provide the tap.

## Architecture

```
RX ch1 (Y-lead) ──► J2 servo header ──► R1 10k ──┬──► GPIO4 (J1 pin 4, steering)
                                            R2 15k ▼ GND
RX ch2 (Y-lead) ──► J3 servo header ──► R3 10k ──┬──► GPIO5 (J1 pin 5, throttle)
                                            R4 15k ▼ GND
J2/J3 + pins (BEC rail) ──► F1 PTC ──► D1 SS34 ──► U2 AP63205 buck (5 V) ──► D2 ──► devkit 5V pin
```

- Divider: 10 k series / 15 k to GND — 5 V rail → 3.0 V at GPIO (3.3 V-safe). Same values
  as the V1 design and the prototype packet.
- D2 (Schottky into the devkit 5 V pin) prevents fights when USB is plugged in while the
  carrier is powered — USB simply wins. Espressif lists the 5 V pin as a supported
  external power input (power sources are "mutually exclusive"; D2 makes simultaneous safe).
- Devkit's own USB-C stays exposed for flashing/bench; BLE for field offload.

## Pin map (devkit header pins, per Espressif user guide v1.1)

| Signal | Devkit pin | GPIO |
|---|---|---|
| Steering (divided) | J1 pin 4 | GPIO4 |
| Throttle (divided) | J1 pin 5 | GPIO5 |
| +5 V in (via D2) | J1 pin 21 | 5V |
| GND | J1 pin 22, J3 pins 1/21/22 | G |

Matches `firmware/rc-pwm-logger/src/board_pins.h` (`esp32-s3-devkit` board, GPIO4/GPIO5) —
**no firmware change needed.**
